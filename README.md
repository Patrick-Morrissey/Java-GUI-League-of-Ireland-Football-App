## League of Ireland Football App

The League of Ireland Football App is a Java GUI application based on League of Ireland football. The application contains a main menu with two sections: a Match Score Tracker and a League Football Shop.

# Features
# Match Score Tracker
- Select home and away teams
- Add and remove players from each team
- Add, subtract and reset goals
- View the current match score
- Show and hide the selected player lists
- End the match and display the result
# League Football Shop
- View items available to purchase
- Add and remove items from the basket
- Change item quantities
- Calculate item and basket costs
- Apply a voucher discount
- Confirm an order

# How to Run
1. Download or clone this repository.
1. Open Command Prompt and change the working directory to the "League of Ireland App Project" folder.
1. Run the command javac FootballAppFrameViewer.java to compile the files.
1. Run the command java FootballAppFrameViewer to run the application.
1. Use the main menu to access the Match Score Tracker or League Football Shop.

I developed the project as part of my Intro to Object-Oriented Programming module in semester 2 of 1st Year using Notepad++.
